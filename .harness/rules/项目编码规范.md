# 项目编码规范

> 硬性约束，每条对应一个历史教训（见 memory）。编码逐条对照，评审逐条核查。

## 时区与限流

- 云函数跑 UTC。按北京日计数（限流等）必须 `new Date(Date.now()+8*3600*1000).toISOString().slice(0,10)`，**不可 `new Date()` 直取 UTC 日**。
- 限流：`featureKey` **每功能独立**（outpaint / caption / avatar …），额度不共享（默认 20 次/日）。`RATE_LIMIT_DAILY` 环境变量配置，免改码重部署。
- `rate_limit` 集合**手动建**（云函数 add 文档但不能建集合）。集合缺失/异常 -> catch 降级 **pass** + `console.error` + `reason`，**不阻塞主流程**。

## 密钥与降级诚实

- SecretId/Key **绝不入前端**（`pages/` 下零 `SECRET_ID`/`SECRET_KEY`）。云函数走 `cloud-secret.js` 优先级：env(`TENCENTCLOUD_*` > 旧名 `SECRET_*`) > `local-config.json`。占位符（`your_`/`你的`/`替换`/`xxxx`/`example`/`placeholder`/`_here`/空）视为未配置。
- **未配置** -> 返回 `demo:true`/`mock:true` 标"示例"；**已配置但调用/解析失败** -> `success:false` + 错误。**绝不静默用 mock 顶替真实答案**。
- 文案诚实：写"AI 配文（混元大模型）"，不夸大模型能力。

## 内容安全（双层 + FAIL_OPEN）

- 前端 `utils/content-check.js` `guardImage/guardText` -> `checkImage` 云函数（`imgSecCheck`/`msgSecCheck`）。服务端 `content-check.js` `assertImageSafe` 兜底。
- 违规提示**不暴露标签/原因**，统一"图片可能包含违规内容，请更换后重试" / "文字内容可能违规，请修改后重试"。
- **FAIL_OPEN**：服务异常（权限/限流/超时）降级 **allow**；仅**确认违规**才拦。图 >1MB 跳服务端检查（前端缩略图为主）。
- `content-check.js` 里 `require('./image-process')` **必须懒加载在函数内**，别提到模块顶（破循环依赖死锁）。

## Hunyuan 与 AI 结构化

- Hunyuan 消息双格式：多模态用 **`Contents` 数组**，纯文本用 **`Content` 字符串**。多轮历史不可混（首轮带图 Contents，追问纯 Content 字符串，图不重传省 token）。
- AI 结构化输出（候选等）用 **3-tier JSON parse**：`JSON.parse` -> 去 ```` ```json ```` fence -> 正则提 `[...]`。prompt 末尾加"只返回纯 JSON 字符串数组，不要 markdown 代码块"，配硬约束（字数/话题数）。

## 图像处理

- `wx.compressImage` **强制 JPG 丢 alpha**。保透明降采样 -> 直绘原图到小画布，别用 compressImage。
- 蓝通道 LSB 隐写被 **JPEG 4:2:0** 抹平。抗 JPEG 须走 luma / DCT 域；PRNG 须可种子化，勿用 `new ImageData`。
- 手写二进制格式（GIF LZW 等）须**用口碑库交叉验证**输出（LZW 码宽递增用 `>`、NETSCAPE2.0 魔数 11 字节）。

## 前端交互

- `dataset.index` 取出是**字符串**，严格比较前须 `Number()` 强转（`0!=="0"` 会让 filter 静默失效）。
- `bindtap` 首参是**事件对象**非业务值；双用途 handler 须 `typeof` 守卫；事件对象无 `stopPropagation`，阻止冒泡用 WXML `catchtap`。

## 设计系统

- 用 `app.wxss` 设计 token（`--color-*`/`--gradient-*`/`--space-*`/`--radius-*`/`--shadow-*`），**不引入 ad-hoc hex**。
- button 文案**单行**（全局 button 强制 `flex` + `nowrap`，长了溢出）。页面自定 `.btn-*` 勿动 `display`/`padding`。暗色网格背景在 `page::before`（z-index:0），内容 z-index:1。

## 命名

- 云函数名：AI 功能 `ai*` 前缀（aiCaption/aiMatting…）；基础设施用动词（checkImage/detectFace/secretCheck）。
- `featureKey`：功能名小写（outpaint/caption/avatar/text2img/style…）。
- 页面名与功能对应（pages/aiOutpaint ↔ aiOutpaint 云函数）。
- 共享 helper 副本顶部标注 canonical 源：`// canonical 源：cloudfunctionTemplate/<file>.js`。

## 红线

- 不在 `pages/` 硬编码密钥或自造 hex 颜色。
- 不静默 mock 顶替真实答案；不暴露内容安全判定原因。
- 不把限流异常当硬失败阻断请求。
- 不在云函数顶层 `require('./image-process')`。
- rebase / 大块交换后必须 grep 核验结构落地（exit 0 ≠ 改动生效）。
