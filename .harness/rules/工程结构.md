# 工程结构

> 不随需求变化的稳定结构约束。新增功能前先对照本文件落位。

## 布局

- **flat 布局**：根目录直接是源码，**无 `miniprogram/` 子目录**。微信开发者工具直接打开项目根。
- 入口：`app.js`（云环境 `cloud1-1gk79pjqd5e1ed35`）+ `app.json`（路由注册）+ `app.wxss`（设计 token）。

## 三层执行 tier

按执行位置分层，不按技术层（无 Controller/Service/DAO）：

| tier | 目录 | 形态 | 特征 |
|---|---|---|---|
| 页面 | `pages/<name>/` | 四件套 `.js/.json/.wxml/.wxss` | 原生组件，**无 UI 库**（Vant 未用）；默认 `usingComponents` 为空 |
| on-device 引擎 | `utils/<name>.js` | 纯 JS 模块 | Canvas 2D + 手写编码器，**离线**，无云依赖 |
| 云函数 | `cloudfunctions/<name>/` | `index.js` + 三件套 + `package.json` + `config.json`(占位) | **隔离部署单元，不能跨目录 require** |

## 共享 helper 规范源

- `cloudfunctionTemplate/` = 三件套 canonical 源：`cloud-secret.js` / `content-check.js` / `rate-limiter.js`。
- 云函数无法跨目录 require，共享靠**复制**。改任一 helper -> **改模板 + 同步所有副本**，不可只改一处。

## 路由与导航

- `app.json` `pages[]` = 路由注册表，**第一个 `pages/index/index` 是入口**。无 tabBar，靠 `index.js` `data.groups` 三组（ai/basic/creative）导航。
- `index.js` 是工具**单一注册表**：新工具必须登记 `{id, name, desc, url, available, isNew}` + `LAUNCH_DATES[id]` + `index.wxss` `.icon-<id>`。NEW 徽章按 `LAUNCH_DATES` 自动管理，**勿手调 `isNew`**。

## 配置与文档

- `config/` = 配置目录（`config/*.json` 已 gitignore，仅 `*.example.json` 入库）。
- `docs/` = 本地文档（**已 gitignore，不入库**）。
- `.harness/` = Harness 资产（rules/skills/agents/changes/mcp），**入库**，团队共享。

## 文件放置规则

| 场景 | 落位 |
|---|---|
| 新页面 | `pages/<name>/` 四件套 + `app.json` pages[] + `index.js` groups 注册 + `LAUNCH_DATES` + `index.wxss` `.icon-<id>` |
| 新 on-device 引擎 | `utils/<name>.js`（被多 page require 时放这） |
| 新云函数 | `cloudfunctions/<name>/` + 从 `cloudfunctionTemplate/` 复制三件套 + `package.json`(wx-server-sdk + tencentcloud-sdk-nodejs) + `config.json`(占位) |
| 改共享 helper | `cloudfunctionTemplate/` + 同步到所有带该 helper 的云函数副本 |
| 业务上下文知识 | `docs/`（本地）；跨会话硬约束写进 `CLAUDE.md` 或 memory |

## 红线

- 不在 `pages/` 引 UI 库或硬编码密钥。
- 不让云函数跨目录 require（复制 helper，别抽公共）。
- 不新建页面却漏登 `app.json` / `index.js` / `LAUNCH_DATES` 任一处。
- 不把 `.harness/` 加进 .gitignore（团队资产）；不把 `docs/` / 密钥文件提交。
