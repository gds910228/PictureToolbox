# spec — feat-greetingLanding-20261024「今日问候·落地与制作页体验」

## 背景

动图版已上线且验证通过。用户反馈三件事：① 分享落地页像"毛坯房"（顶部日期条内容少、
下方大片空白）；② 分享卡片封面看不到主图和祝福语（默认截图混入界面文字 / 3:4 成品图
被 5:4 卡片居中裁切裁掉文字）；③ 制作页操作按钮悬空、缺步骤指引。四点全做，
**作品上传云存储明确不做**。

## 四点方案

1. **顶部页头丰富化**：大字 = 节日/节气名 || 时段问候词（随打开时间切换）；小字 = 日期；
   加"今日祝福 · <每日轮换祝福句>"（复用 getBlessingPool + 日期种子，与默认选中句同源）。
2. **步骤 1 下方填充**：今日祝福卡（祝福句 + 「用这句」一键选入祝福语）。
   节日日历条/作品再发 → 二期不做。
3. **制作页 UI/UX**：
   - **底部固定操作区**（三步统一，含 safe-area）：步骤1 = 选照片/下一步；步骤2 = 生成/上一步；
     步骤3 = 发给亲友 + (保存|分享) 半宽并排；内容区 padding-bottom 让出空间；
   - **步骤指示**（全步常驻）：1 选照片 → 2 写祝福 → 3 发亲友，当前步高亮；
   - **重复入口收敛**：未选照片时隐藏虚线"＋"格（大按钮为唯一入口），有照片后格子变追加入口；
   - **分享落地欢迎条**：src=share 进入且用户未永久关闭时显示"朋友分享给你的问候小工具…"
     （可关闭，storage 记忆）。
4. **专属 5:4 分享封面**：`_renderCover()` 1080×864 紧凑构图——小标题（节日/时段+日期）
   → 照片卡 → 祝福语放大置底；静图/动图统一用此封面（动图不再走默认截图）；
   分享标题个性化（"我做了张霜降问候，你也来一张？"）。

## 验证

node 侧：语法 + 封面布局坐标数学 + 进度/日期逻辑实测。真机：15+ 用例见 test_report。
