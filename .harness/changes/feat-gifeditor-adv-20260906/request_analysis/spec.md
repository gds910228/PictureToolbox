# 需求规格：GIF 编辑器进阶编辑能力包

- 类型：feat
- 创建：2026-09-06
- 执行层：on-device（零新依赖、零云函数）
- 前置：GIF 解码器/差量编码器/编辑器基础

## 1. 画布裁剪
- 预览画布上提供裁剪框：1:1 / 4:3 / 16:9 / 9:16 / 自由
- 裁剪框可拖拽移动、四角/四边调整大小，最小 16px，不超出画布
- 确认后应用到所有帧（像素区域变化，帧序/延时不变）
- 导出尺寸=裁剪尺寸
- 一键撤销恢复裁剪前状态

## 2. 文字覆盖
- 多条文字管理（增/删/改）
- 属性：内容、字号(16/24/36/48)、颜色(设计 token 色板 7 色)、不透明度(20-100%)、描边开关
- 位置：九宫格快速定位 + 自由拖拽
- 作用范围：全部帧 / 指定帧区间
- 文字渲染进帧像素，导出生效，差量编码 dirty-rect 自动覆盖文字区域
- 预览实时可见

## 3. 逐帧画笔消除
- 画笔粗细：4/12/24px
- 仅当前帧擦除，擦除区域 alpha=0
- 每帧独立撤销/重做栈（≥10 步），帧切换栈隔离
- 透明在差量导出中保持 alpha=0

## 4. 大 GIF 体验
- 缩略图懒加载：可视区外不生成，每批 8 帧，滚动触发
- 60 帧以上滚动不卡
- 解码/导出进度条 + 分步提示

## 5. 验证标准
- node 自测：裁剪像素正确、擦除 alpha=0、透明经 buildGIFDiff round-trip 保持、裁剪后帧数/延时/尺寸正确
- 全量回归：87 解码器测试 + 74 进阶测试 + fuzz 3 个新种子
- 页面手动验证用例
