## 手动验证用例（真机/开发者工具）

### V1：画布裁剪-比例
- **操作**：进入裁剪模式 → 选 1:1 → 拖拽裁剪框 → 确认
- **预期**：所有帧裁剪为正方形；导出 GIF 尺寸=裁剪尺寸；帧延时不变
- **证据**：预览区尺寸变化；导出后第三方工具确认尺寸

### V2：画布裁剪-自由拖拽
- **操作**：裁剪模式 → 自由 → 拖拽四角调整 → 拖中央移动
- **预期**：裁剪框不超出画布；最小 16px；确认后生效
- **证据**：边界不越界；小尺寸时手柄不消失

### V3：裁剪撤销
- **操作**：裁剪确认后 → 点"撤销裁剪"
- **预期**：恢复裁剪前尺寸和所有帧像素
- **证据**：预览区恢复原尺寸；帧内容完整

### V4：文字添加-全部帧
- **操作**：文字模式 → 输入"Hello" → 选字号/颜色/描边 → 九宫格选位置 → 添加
- **预期**：预览所有帧显示文字；导出 GIF 文字可见
- **证据**：播放时文字在所有帧上；导出文件文字像素正确

### V5：文字-帧区间
- **操作**：添加文字 → 作用范围选"区间" → 设 2~4 帧
- **预期**：仅第 2-4 帧显示文字，其他帧无
- **预期**：播放时文字在区间内出现/消失

### V6：文字拖拽
- **操作**：文字模式 → 拖拽预览中的文字
- **预期**：文字跟随手指移动；导出后位置正确
- **证据**：文字实时跟随；不超出画布

### V7：文字编辑/删除
- **操作**：点击列表中文字 → 修改内容/颜色 → 更新；或点 × 删除
- **预期**：修改实时反映到预览；删除后文字消失

### V8：擦除-画笔
- **操作**：擦除模式 → 选 12px → 在画布上涂抹
- **预期**：涂抹区域变透明（棋盘格可见）；仅当前帧受影响
- **证据**：切换帧其他帧不变；擦除区域 alpha=0

### V9：擦除-撤销/重做
- **操作**：擦除几笔 → 点撤销 → 点重做
- **预期**：撤销恢复擦除前状态；重做重新擦除
- **证据**：画布像素恢复/重擦；按钮状态正确

### V10：擦除-帧隔离
- **操作**：在帧 1 擦除 → 切到帧 2 擦除 → 切回帧 1
- **预期**：帧 1 的擦除保留；帧 2 独立；各帧撤销栈独立
- **证据**：帧 1 擦除区域仍透明；撤销只影响当前帧

### V11：擦除-透明导出
- **操作**：擦除部分区域 → 导出 GIF
- **预期**：导出 GIF 中擦除区域保持透明
- **证据**：在支持透明的查看器中确认 alpha=0

### V12：大 GIF 懒加载
- **操作**：选择 60 帧 GIF → 滚动帧列表
- **预期**：首屏快速显示（仅前 8 帧缩略图）；滚动时渐进加载；不卡顿
- **证据**：加载时间短；滚动流畅；缩略图逐步出现

### V13：解码进度
- **操作**：选择大 GIF
- **预期**：显示进度条和"解码中.../生成缩略图..."分步提示
- **证据**：进度条可见；无长时间无响应

### V14：导出进度
- **操作**：编辑后点导出
- **预期**：显示"合成帧 X/Y"→"差量编码中"→"写入文件"进度
- **证据**：进度条递增；完成后显示结果

### V15：组合操作
- **操作**：裁剪 → 添加文字 → 擦除 → 倒放 → 调速 → 导出
- **预期**：所有编辑叠加生效；导出 GIF 正确
- **证据**：预览显示所有编辑；导出文件无花屏/丢帧

### V16：回归-基础功能
- **操作**：多选删除、区间截取、倒放、调速
- **预期**：原有功能正常
- **证据**：与上一版本行为一致

### V17：回归-makeGif
- **操作**：进入 GIF 制作，多图合成
- **预期**：功能完全正常
- **证据**：buildGIF 未修改；makeGif 页面未改动
