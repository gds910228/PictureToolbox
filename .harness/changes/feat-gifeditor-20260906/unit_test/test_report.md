## V1：选择并解码正常 GIF
- **操作**：首页创意玩法 → GIF编辑器 → 点击"从聊天文件选择" → 选一个多帧 GIF
- **预期**：显示文件名/尺寸/帧数/大小；帧列表显示缩略图+帧号+延时
- **证据**：Console 无 error；帧列表缩略图正常渲染；信息区数据正确

## V2：非 GIF 文件友好报错
- **操作**：选择一个 .jpg/.png 文件（或从相册选择被转码的图片）
- **预期**：弹出 modal "不是 GIF 文件"，提示可能被相册转码
- **证据**：不出现解码崩溃；modal 文案正确；Console 有 warn 但无未捕获异常

## V3：超大 GIF 拦截
- **操作**：选择 >480px 或 >40 帧的 GIF
- **预期**：弹出 modal 说明尺寸/帧数超限
- **证据**：不进入编辑界面；内存不暴涨；modal 文案含具体数值

## V4：多选删除帧
- **操作**：点"多选" → 选中若干帧 → 点"删除(N)"
- **预期**：选中帧被移除；帧列表重新编号；剩余帧 ≥ 1
- **证据**：帧数减少；帧号连续从 1 开始；导出后帧数正确

## V5：区间截取
- **操作**：选择起始帧和结束帧 → 点"截取" → 确认
- **预期**：只保留区间内帧；帧列表更新
- **证据**：帧数 = 结束-起始+1；首尾帧内容正确

## V6：倒放
- **操作**：点"反转帧序" → 确认
- **预期**：帧顺序反转
- **证据**：第一帧变为原最后一帧；播放时画面倒序

## V7：调速
- **操作**：分别点 0.5x / 1x / 2x
- **预期**：预览播放速度变化；导出后 GIF 帧延时相应变化
- **证据**：0.5x 时 delayMs×2；2x 时 delayMs÷2；用第三方工具打开导出文件确认延时

## V8：实时预览播放
- **操作**：点预览区"播放"
- **预期**：canvas 按帧延时循环播放；显示当前帧号/速度
- **证据**：动画流畅；帧号计数器递增并循环；点"停止"暂停

## V9：导出 GIF 并保存
- **操作**：编辑后点"导出 GIF" → 等待编码 → 点"保存到相册"
- **预期**：导出成功；显示文件大小；保存到相册
- **证据**：Console 无 error；toast "导出成功"；相册中 GIF 可播放

## V10：分享
- **操作**：右上角分享给朋友/朋友圈
- **预期**：分享卡片标题正确，点击进入 GIF编辑器
- **证据**：分享 path 为 `/pages/gifEditor/gifEditor`

## V11：首页入口与 NEW 标签
- **操作**：回到首页
- **预期**：创意玩法组中 GIF编辑器 在 GIF制作 之后；显示 NEW 标签；图标正常渲染
- **证据**：点击可进入页面；NEW 标签 14 天后自动消失

## V12：回归：GIF制作不受影响
- **操作**：进入 GIF制作，正常多图合成 GIF
- **预期**：功能完全正常
- **证据**：gif-encoder.js 未被修改；makeGif 页面无变更；合成/保存正常

## V13：透明 GIF 解码
- **操作**：选择含透明背景的 GIF
- **预期**：透明区域在预览中显示棋盘格/透明；导出后透明度保留
- **证据**：预览 canvas 中透明区域 alpha=0；导出 GIF 在支持透明的查看器中正常

## V14：隔行扫描 GIF
- **操作**：选择 interlaced GIF
- **预期**：画面正确，无行错位
- **证据**：与系统相册/其他 GIF 查看器对比画面一致
