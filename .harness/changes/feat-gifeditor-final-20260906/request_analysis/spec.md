# 需求规格：GIF 编辑器最终能力包

- 类型：feat
- 创建：2026-09-06
- 执行层：on-device（零新依赖、零云函数）

## 1. 自适应调色板
- 复用 utils/color-quantize.js 的 medianCut，每次编码生成 ≤255 色调色板
- 256 槽保留 1 槽透明索引，LZW minCodeSize 按色数自适应（2-8）
- 差量路径同样受益（全局调色板，非帧级）
- 画质对比数据表：固定 vs 自适应在渐变/照片样本上的 ±8 匹配率与体积
- 屏幕录制类差量缩减率劣化 ≤5%
- 回归红线：makeGif 不传新参数时 buildGIF 字节级不变

## 2. 拆帧导出
- 全部或勾选帧导出为 PNG
- 逐帧保存到相册，命名 gifEditor_frame_001.png
- 批量进度反馈
- 与 makeGif 互相引流

## 3. 信息面板 + 草稿
- 信息面板：版本/尺寸/帧数/延时分布/体积/量化方式
- 草稿：持久化编辑状态，再次进入可恢复
- Storage 策略：源文件存 USER_DATA_PATH，操作日志存 wx.storage（<10KB/key），24h 有效

## 4. 验证
- node 自测：画质数据、调色板回归、makeGif 字节对照、透明 round-trip
- 全量回归：87+74+51 单测 + fuzz 3 新种子
- 手动用例：页面交互
