## 手动验证用例（真机/开发者工具）

### V1：自适应调色板
- **操作**：加载彩色照片类 GIF → 开启"画质增强"→ 导出
- **预期**：导出 GIF 色彩更接近原图；文件体积可能略增
- **证据**：与固定色板导出对比，色彩过渡更平滑

### V2：固定色板回归
- **操作**：不开启"画质增强"→ 导出
- **预期**：与上一版本行为完全一致
- **证据**：文件大小/画质与旧版相同

### V3：拆帧导出-全部帧
- **操作**：加载 GIF → 点"拆帧导出 PNG"
- **预期**：逐帧保存到相册，命名 gifEditor_frame_001.png 等
- **证据**：相册中出现对应数量 PNG；进度条递增

### V4：拆帧导出-选中帧
- **操作**：多选模式选中若干帧 → 拆帧导出
- **预期**：仅导出选中帧
- **证据**：相册中 PNG 数量=选中数

### V5：拆帧导出-文字烘焙
- **操作**：添加文字 → 拆帧导出
- **预期**：导出的 PNG 包含文字
- **证据**：相册中图片可见文字

### V6：信息面板
- **操作**：点"信息"
- **预期**：显示版本/尺寸/帧数/延时分布/体积/量化方式
- **证据**：数据与实际 GIF 一致

### V7：草稿保存与恢复
- **操作**：加载 GIF → 添加文字/擦除/调速 → 退出页面 → 重新进入
- **预期**：显示"检测到未完成的编辑草稿"→ 点恢复 → 编辑状态还原
- **证据**：文字/擦除/调速恢复；画布显示正确

### V8：草稿丢弃
- **操作**：草稿提示时点"丢弃"
- **预期**：草稿清除，正常选择新文件
- **证据**：不再提示草稿

### V9：草稿过期
- **操作**：24 小时后进入
- **预期**：草稿自动失效，不提示
- **证据**：无草稿提示

### V10：交叉引流
- **操作**：GIF 编辑器底部点"前往 GIF制作"；GIF 制作底部点"前往 GIF编辑器"
- **预期**：互相跳转
- **证据**：navigator 正确导航

### V11：大 GIF 拆帧进度
- **操作**：加载 60 帧 GIF → 拆帧导出
- **预期**：进度条逐帧更新，不卡死

### V12：全功能组合
