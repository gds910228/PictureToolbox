- 创建：2026-10-25（北京）

- 驳回文：**"AI生成功能存在未授权公众人物人脸或声音数据生成服务，涉嫌肖像权及个人信息违规。

## 定性

深度合成新规（肖像权/个人信息）合规要求，非代码缺陷。aiAvatar（上传人脸→生成新形象）
是深度合成教科书场景；"声音"为审核模板通用措辞（无语音功能可无视）；本项目风格模板
为场景模板不含名人预设脸，**无需下架**。抠图/上色/消除属"处理"非"合成"，本轮不动。

## 整改内容（四层）

1. **授权弹窗**（审核明确要求）：新共享组件 `components/face-consent/`（深色霓虹皮肤），
   文案四要素：技术说明（深度合成）/ 授权确认（含"请勿上传公众人物照片"警示，高亮）/
   用途限制（禁止冒充与违法）/ 数据留存（"离开页面后自动删除"——由 cleanup 兑现，非话术）。
   触发：**生成动作前拦截**（aiAvatar 仅人像模式；aiStyle 全部），带"7 天内不再提示"勾选
   （`utils/face-consent.js` 记忆，两功能共用同一授权 key）。
2. **用后即删**：云函数 aiAvatar 新增 `action:'cleanup'`（删除上传原图，不计数不检测）；
   前端三重保障——onUnload 删当前图、上传成功写 storage 清理标记、下次进入兜底删残留
   （杀进程漏删补删）。换风格/再生成体验不受影响（会话内保留 fileID）。
3. **页面文案**：aiAvatar 上传提示追加"请使用本人或已获授权的照片，请勿上传公众人物照片"；
   合规提示补"仅供个人娱乐使用"（GenerateAvatar 已有 LogoAdd=1 图内水印，文字标识双保险）。
4. **弹窗挂起回放**：生成入口 startGenerate 改拦截器（挂起 overrideStyle，同意后续跑），
   随机盲盒/再生成路径同样覆盖；自检通过（按钮/盲盒/萌宠三分支 + 回放）。
