# 需求规格：GIF 工具链收官

- 类型：feat
- 创建：2026-09-06
- 执行层：on-device（零新依赖、零云函数）

## 1. 批量 GIF 处理（pages/gifBatch/）
- wx.chooseMessageFile 多选 ≤9 个 .gif
- 队列 UI：文件名/体积/帧数/状态/进度
- 每文件：调速/倒放/压缩/统一裁剪
- 串行处理、重试/移除、批量导出
- 首页注册 4 处

## 2. GIF 压缩专项（utils/gif-compress.js）
- 目标体积模式（≤N MB）
- 策略阶梯：空间缩放 + 帧抽取（保首尾与时长）+ 调色板控制
- 达标即停，否则返回最优
- 数据表：3 类样本 × 3 档目标

## 3. 帧特效（utils/gif-effects.js）
- 发光描边、故障风、暗角、淡入淡出
- 纯函数，node 可测
- 文字动画：帧区间淡入淡出

## 4. 超大 GIF 流式
- decodeGifChunked：先解析后分批合成
- 进度回调、取消支持
- >5MB 或 >4M 像素自动启用

## 5. 全链路加固
- Pipeline e2e 测试
- Fuzz D：随机编辑序列 500 迭代
- 前五轮全部测试 + 3 新 fuzz 种子
