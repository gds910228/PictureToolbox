## 一、生成与渲染

| # | 用例 | 预期 |
|---|---|---|
| 1 | 动效默认"不动" | 生成流程与原静图完全一致（JPG，回归无变化） |
| 2 | 选"文字呼吸"生成 | loading 提示"动图生成中..."；成品为 GIF，祝福语透明度+光晕周期性脉动（1.2s 循环），全程可读 |
| 3 | 选"逐字浮现"生成 | 祝福语逐字出现（1s 内打完）后整句停留约 0.6s，循环播放（1.6s 周期） |
| 4 | 多张照片（2/3/4 张）+ 动效 | 照片分格各帧一致不闪动，仅文字动 |
| 5 | 静图→动图→静图连续生成 | 画布分辨率切换后内容正常（无缩放错位/残影） |
| 6 | 低端安卓机生成耗时 | loading 期间 UI 不冻结；耗时 >3s 时有明确提示 |
| 7 | 文件大小（dither 已开） | 记录实测值；渐变区色带应明显改善；若超 4MB → 降帧（12→10）重测 |
| 7b | 照片缓推 | 动效态照片缓慢推近再回位（峰值 1.05，循环无缝），照片不抖不跳；静图态无缩放 |
